How to get your access token
  1. Open GitHub, then Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Repository access: choose Only select repositories and pick this repository.
  3. Permissions, Repository permissions: set Contents to Read and write.
  4. Generate, copy the token (starts with github_pat_) and paste it below.

The token stays in this browser only. It is sent only to api.github.com.
